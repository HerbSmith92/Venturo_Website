# Venturo architect pack

Drop brand, design, and product source files here. These folders are the source of truth for the website, app, and backend work that follows.

Paste files as they are. Do not worry about renaming unless a file is unclear. PDF, PNG, JPG, SVG, Figma exports, Word, Google-doc downloads, `.ttf` / `.otf` / `.woff2`, and short notes all work.

## Where to paste

| Folder | What to drop |
| --- | --- |
| [`01-product-brief`](01-product-brief) | Product notes, pricing, audience, feature lists |
| [`02-brand-guide`](02-brand-guide) | Brand guide PDF / slides, colour, usage rules |
| [`03-brand-voice`](03-brand-voice) | Tone of voice, do/don't copy, sample writing |
| [`04-fonts`](04-fonts) | Licensed font files and font licences |
| [`05-logos-and-marks`](05-logos-and-marks) | Logo lockups, icons, favicon, app icon |
| [`06-design-prototypes`](06-design-prototypes) | Website, app, and marketing mockups |
| [`07-imagery-and-video`](07-imagery-and-video) | Photography, illustration, motion, stock |
| [`08-icons-and-ui`](08-icons-and-ui) | Icon sets, UI kits, component screenshots |
| [`09-ux-flows`](09-ux-flows) | User journeys, sitemaps, wireframes |
| [`10-copy-and-messaging`](10-copy-and-messaging) | Headlines, page copy, onboarding, emails |
| [`11-legal-and-policies`](11-legal-and-policies) | Terms, privacy, membership terms |

## Locked system

Read [`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) and [`03-brand-voice/BRAND_VOICE.md`](03-brand-voice/BRAND_VOICE.md) before designing or writing UI.

## How this will be used

1. Colour, type, logo, and UI rules are locked in `DESIGN_SYSTEM.md`
2. Voice and writing rules are locked in `03-brand-voice/`
3. Screens still need prototypes in `06-design-prototypes/`
4. Membership, directory, events, and community flows still need a sitemap in `09-ux-flows/`

## File tips

- Keep original filenames if they are already clear (`Venturo-Brand-Guide-v3.pdf` is fine)
- If two files conflict, add a version in the name (`brand-guide-v4.pdf`)
- Large video files can stay here; say if a file should not be committed to git
