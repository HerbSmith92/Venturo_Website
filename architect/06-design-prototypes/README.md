# Design prototypes

Drop mockups, screenshots, and exported frames here.

Use the subfolders:

- `website/` — marketing site, directory, events, account, join
- `app/` — member app screens that the website should match or support
- `marketing/` — ads, social, email, print

Useful files:

- Figma / Adobe XD / Sketch exports (PNG, PDF)
- Clickable prototype links in a `.txt` file
- Annotated screenshots

Name files by screen when you can, for example `home.png`, `directory-list.png`, `event-detail.png`, `join.png`.
